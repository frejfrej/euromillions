# Local Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `euromillions serve` starts a local web server with four screens (Numbers, Patterns, Suggest, Backtest) over the existing analysis, suggestion and backtest code.

**Architecture:** A standard-library `ThreadingHTTPServer` bound to 127.0.0.1 serves static HTML/CSS/JS from the package and a small JSON API. `web/api.py` turns domain objects into JSON-ready dicts (pure, unit-tested); `web/server.py` does HTTP, the `Host` check and the single background backtest job. Figures the CLI computes inside its formatting code move to `backtest.py` / `analyzer.py` so both front ends share them.

**Tech Stack:** Python ≥ 3.10 standard library (`http.server`, `threading`, `json`, `webbrowser`), click (existing), vanilla HTML/CSS/JS with no build step.

**Spec:** `docs/superpowers/specs/2026-11-15-web-ui-design.md`

## Global Constraints

- No new runtime dependency; no npm, framework, bundler or CDN; no web fonts (system UI stack).
- Server binds `127.0.0.1` only; requests whose `Host` is not `127.0.0.1:<port>` or `localhost:<port>` get 403.
- Every figure comes from Python; JavaScript only formats and draws.
- Every page carries the disclaimer: "Lottery draws are random: past results cannot predict future ones. For educational and entertainment purposes only." (`cli.DISCLAIMER`).
- The CLI's output does not change: the existing `tests/test_cli.py` passes unmodified.
- `ruff check`, `ruff format --check`, `mypy --strict` (src and tests) clean; `pytest` (warnings are errors) green and offline.
- Z-score palette: `#b8322f` (z ≤ −2, white text), `#ee9693` (−2 < z ≤ −1), `#f0efec` (−1 < z < 1), `#86b6ef` (1 ≤ z < 2), `#1c5cab` (z ≥ 2, white text); bars `#2a78d6`; stars `#f2b632` with dark text; z-score written in every grid cell.
- Touch targets ≥ 44 px; real `<button>`, `<input>`, `<label>`; text contrast ≥ 4.5:1.

## Review Focus

- **A cache that is missing or behind** — `serve` starts anyway; `/api/status` says `cache: false` / `behind: true`; pages show "No draw history yet" with a Download button. Test in Task 4.
- **Bad query values** (`lines=abc`, `window=0`, `seed=1.5`, unknown strategy, `trainFraction=0.2` before the current rules) — 400 with the library's message, never a 500 or a hung job. Tests in Tasks 3 and 4.
- **Two backtests started at once / Cancel with nothing running** — second POST gets 409; DELETE when idle is a no-op 200 returning the idle state. Test in Task 4.
- **Update data while a backtest runs** — the running backtest keeps its own history copy; the fetch succeeds and new requests see the new draws. Test in Task 4.
- **Requests with a foreign `Host` header** (DNS rebinding) — 403 on pages and API alike. Test in Task 4.

**Files:**

**Interfaces:**
- Produces, in `backtest.py`:
  - `ProgressCallback = Callable[[int, int], None]`
  - `backtest(..., progress: ProgressCallback | None = None) -> Backtest` — called with `(done, total)`, `total = len(unique strategies) * test_draws`, once after each draw played by each strategy (so the last call is `(total, total)`). An exception from the callback propagates.
  - `Z_BEYOND_TWO: float` — `2 * (1 - NormalDist().cdf(2))` (about 1/22).
  - `def chance_of_extreme_z(count: int) -> float` — `1 - (1 - Z_BEYOND_TWO) ** count`.
  - `def edge_threshold(count: int) -> float` — `NormalDist().inv_cdf(1 - 0.05 / (2 * count))`.
  - `TOP_RANK_ODDS: float` — `1 / sum(RANK_PROBABILITIES[r] for r in 1..TOP_RANKS)` (about 2.1 million).
  - `def win_rate_sd(lines: int) -> float` — `sqrt(WIN_PROBABILITY * (1 - WIN_PROBABILITY) / lines)`.
  - `def expected_wins(lines: int) -> dict[int, float]` — `lines * RANK_PROBABILITIES[rank]` for every rank.
  - `FEW_LINES = 1000` (moved from `cli._FEW_LINES`).

### Task 4: HTTP server (`web/server.py`)

**Files:**
- Create: `src/euromillions/web/server.py`, `src/euromillions/web/static/` (placeholder `index.html` so static serving can be tested; real pages in Tasks 6–9)
- Test: `tests/test_web_server.py`

**Interfaces:**
- Consumes: Task 3 payloads; `fetcher.load_draws`, `fetcher.update_cache`, `backtest.backtest`.
- Produces:
  - `class App` — holds `cache_path: Path`, a lock, the loaded draws (reloaded when the cache file's mtime changes) and the `BacktestJob`.
  - `class BacktestJob` — `start(draws: list[Draw], settings: dict[str, Any]) -> None` (raises `JobRunning`), `cancel() -> None`, `snapshot() -> JSON` (`{state: "idle"|"running"|"done"|"failed"|"cancelled", done, total, settings, result, error}`); runs `backtest()` in a daemon thread with a progress callback that raises a private `_Cancelled` when cancelled.
  - `def make_server(cache_path: Path, port: int) -> ThreadingHTTPServer` — binds `("127.0.0.1", port)`; `server.server_address[1]` is the real port (port 0 allowed).
  - Routes: `GET /` → `index.html`; `GET /<name>.html|.css|.js` from `static/` (no path traversal: only names in the directory); `GET /api/status`, `POST /api/fetch` (JSON body `{"force": bool}`, optional), `GET /api/analysis?window=&top=`, `GET /api/suggest?strategy=&lines=&window=&seed=`, `POST /api/backtest` (JSON body `{strategies, trainFraction, lines, window, seed, refresh, price}`, all optional, CLI defaults), `GET /api/backtest`, `DELETE /api/backtest`.
  - Status codes: 200; 202 for a started backtest; 400 for `ValueError` (bad parameter, including `HistoryError` from a bad split); 403 for a foreign `Host`; 404 unknown path; 405 wrong method; 409 for `JobRunning` and for "no history yet" (message: `no draw history yet: use Update data to download it`); 500 for `CorruptCacheError` (message plus "Delete that file and update the data again."); 502 for `FetchError`. Body always `{"error": message}` on failure.
  - Responses carry `Cache-Control: no-store` and the right `Content-Type`; the handler's `log_message` is silenced.
